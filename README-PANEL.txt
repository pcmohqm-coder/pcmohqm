راهنمای نسخه آزمایشی ثبت‌نام و ورود — خدمات فنی محمد
=====================================================

این نسخه PHP است و روی هاست معمولی (cPanel / DirectAdmin) کار می‌کند. GitHub Pages این بخش را اجرا نمی‌کند.

نیازها: PHP 8 یا بالاتر (با pdo_sqlite) و SSL فعال روی دامنه pcmohqm.ir

مراحل آپلود:
1. محتوای کل این پوشه را در public_html هاست آپلود کن (index.html باید مستقیم داخل public_html باشد).
2. مطمئن شو پوشه data/ برای PHP قابل نوشتن است (دسترسی 755 یا 775).
3. در api/config.php مقدار secret را به یک رشته طولانی و تصادفی تغییر بده.
4. ایمن‌تر: پوشه data را بالاتر از public_html ببر و مسیر db_file را در config.php اصلاح کن.

حالت آزمایشی (dev_mode = true):
- پیامک و ایمیل ارسال نمی‌شود؛ کد تأیید داخل صفحه نمایش داده می‌شود تا همه چیز را تست کنی.
- قبل از باز کردن سایت برای مردم حتماً در api/config.php مقدار dev_mode را false کن.

اتصال پیامک (کاوه‌نگار):
- در پنل کاوه‌نگار یک قالب «تأییدیه/verify» با یک متغیر (token) بساز، مثل: کد تأیید شما: %token
- api_key و template را در api/config.php پر کن.

ایمیل:
- فرستنده را روی دامنه خودت بساز (no-reply@pcmohqm.ir) در پنل هاست؛ این ایمیل در config.php تنظیم شده است.
- اگر ایمیل‌ها به اسپم می‌روند، بعداً به SMTP اختصاصی تغییرش می‌دهیم.

آدرس‌ها: auth.html (ثبت‌نام/ورود)، panel.html (پنل کاربر)

پنل مدیریت (admin.html) — ویرایش کل سایت
----------------------------------------
تب‌ها: متن‌های سایت (عنوان‌ها، دکمه‌ها، لینک‌های ارتباطی، درباره ما، فوتر)، خدمات (افزودن/حذف/جابه‌جایی)، سؤالات متداول، نمونه کار و تبلیغ (آپلود عکس/ویدیو)، کاربران (فهرست و حذف).
متن خالی = بازگشت به پیش‌فرض. تغییرات بلافاصله در سایت اعمال می‌شود.

1. در api/config.php جلوی 'admins' شماره موبایل یا ایمیل خودت را بنویس، مثل: 'admins' => ['09123456789'],
2. با همان شماره در سایت ثبت‌نام کن و تأیید کن (یک بار).
3. به آدرس pcmohqm.ir/admin.html برو؛ فرم افزودن نمونه کار و تبلیغ را می‌بینی.
4. پوشه uploads باید برای PHP قابل نوشتن باشد (دسترسی 755 یا 775).
5. اگر آپلود ویدیو خطا داد، حد upload_max_filesize و post_max_size هاست را در پنل (Select PHP Version / Options) روی 64M بگذار.

فونت‌ها: وزیرمتن (متن) و لالزار (تیترهای درشت) — داخل assets/fonts قرار دارند و به اینترنت خارجی نیاز ندارند (مجوز OFL).
